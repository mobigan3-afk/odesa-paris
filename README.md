# Одесса → Париж — Android-проект (APK)

Игра запускается внутри WebView в полноэкранном горизонтальном режиме. Сохранения хранятся на устройстве.
Кнопка «Назад»: первое нажатие — пауза, два нажатия подряд — выход.

## Как получить APK

**Вариант 1. GitHub (без Android Studio)**
1. Создайте репозиторий на github.com и загрузите в него ВСЁ содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку Actions → «Build APK» → Run workflow (или просто дождитесь запуска после загрузки).
3. Когда сборка завершится, скачайте файл `OdesaParis-apk` → внутри `app-debug.apk`.

**Вариант 2. Android Studio**
1. File → Open → выберите эту папку, дождитесь синхронизации Gradle.
2. Build → Build APK(s). Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка
Скопируйте `app-debug.apk` на телефон и разрешите установку из неизвестных источников.
Для Google Play нужна release-сборка с вашей подписью (Build → Generate Signed Bundle / APK).

## Обновить игру
Замените файл `app/src/main/assets/index.html` новой версией игры и пересоберите.

Примечание: шрифт Press Start 2P подгружается из интернета; без сети будет моноширинный шрифт по умолчанию.
